# 港股交易工作台

## 双市场量化与白色主题

“量化与比特币”支持港股和比特币现货均线交叉策略，配置快慢周期、资金、投入比例、手续费、滑点及港股每手股数。港股沿用 OpenD，比特币通过 MIT 许可的 CCXT 公共行情接口连接 OKX / Binance / Kraken。无需交易所密钥，交易对须被所选行情源支持。

支持历史回测和持续模拟账户。持续模拟每30秒检查已收盘K线，启动先预热，收盘信号在下一根开盘模拟成交；成交记录需等该根收盘后可观察。跨过多根行情时跳过并重新预热。账户资金、持仓和参数保存在本机。新建账户会重置旧模拟账户，暂停不会平仓。未实现真实券商或交易所下单。

BTC 行情最多500根、按 UTC 显示；港股沿用香港时间轴，不复权，税费需计入自定义成本，企业行动可能影响结果。均线策略只做多，无杠杆；期末权益含未平仓估值，回测盈利不代表真实收益。顶部白色/深色主题按钮会保存本浏览器选择。

本机运行的港股监控、K线分析与复盘系统，基于富途 OpenD。支持 Windows、macOS 代码适配与 iPhone Bark 提醒。

## 使用流程

1. 安装 Python 3.10–3.12 和富途官方 OpenD，启动 OpenD 并登录。仓库不包含安装包或账号。
2. 按 [README](README.md) 安装依赖；macOS 运行 `.venv/bin/python launch.py`，Windows 运行 `Start-Monitor.ps1`。
3. 在“监控模式”中保存规则，再查看信号和 K线；在“交易复盘”中添加标签、笔记和导出记录。
4. 在“提醒与设置”中填入 Telegram / Bark 凭据，然后自行发送测试提醒。桌面提醒与手机提醒分别启停。

## macOS 与 iPhone

- Safari 可以使用本机网页工作台。
- macOS 桌面提醒使用系统通知中心；凭据存入系统钥匙串，可能需要用户允许当前 Python 进程访问。
- iPhone 使用 Bark 接收推送；本版没有把完整工作台开放到局域网或公网。
- Apple Silicon 和 Intel Mac 需使用匹配系统架构的 Python、官方 OpenD；实际行情、系统通知和手机送达需要在设备上验证。
- [macOS 安装及常见问题](docs/MACOS.md)。

## 模式与复盘

急跌、区间成交量、向上突破模式支持自由命名和独立启停，可调整窗口、阈值、预热、冷却、最低价格、最低当日成交额、自选范围和手机提醒。修改规则后重新预热。

复盘保存触发时参数，并记录可观察到的 5/15/30 分钟后原始价格变化；休市、断线或缺样本显示空值。上涨占比不等于交易胜率。K线回放隐藏未来指标，不包含撮合、持仓、手续费或成交回测。

## 隐私与开源

运行数据保存在系统数据目录，凭据通过 Windows DPAPI 或系统钥匙串保护。仓库仅包含代码、合成测试、文档及前端组件，排除日志、数据库、备份、个人配置和 OpenD 安装包。发布前检查见 [隐私说明](docs/PRIVACY.md)。

配置 API 不回显密钥及接收 Chat ID；输入框留空保留旧值。提醒内容只在启用指定手机渠道时发给 Telegram 或 Bark，不会上传到 GitHub。发布仓库的 GitHub 账号名本身是公开的。

项目采用 MIT 许可证，保留图表组件原许可证。Windows 已本机测试，macOS 适配和模拟测试不等于真机验证；CI 的结果以 GitHub 实际运行状态为准。
